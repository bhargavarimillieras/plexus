# Plexus

A ward / night-shift board that runs entirely in the browser.

- `index.html` — Plexus (starts empty)
- `sandbox.html` — Plexus with demo patients, for trying things out

**This repository holds the app only. No patient data is ever stored here.**
Plexus saves to a data file you choose on hospital storage (network drive / hospital OneDrive).

> Never upload data files (`*.json`), backups or screenshots of the board to this repository.
